# Virtual World Observation Contract

## Objective
Add a read-only virtual world observation contract.

This is a schema/contract/test-surface only.
It does not implement a virtual world engine.
It does not mutate virtual world state.
It does not create persistent world state.
It does not assert virtual observations as external reality.

## Constraints
* No runtime mutation.
* No memory write.
* No self-model update.
* No affect/hormone transition.
* No persistence enablement.
* No vector/vocab/subset read or load.
* No OCR/STT/model/device activation.
* No AGP/fallback bypass.

## Features
Exposes functions for building the contract, extracting summaries, and linking to downstream plans (origin fact status, multimodal event candidate, cross-modal binding preflight, memory candidate, appraisal, AGP input).
